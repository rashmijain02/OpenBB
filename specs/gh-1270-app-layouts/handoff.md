## What changed

- **Debt.** The three #1270 entries (`apps.custom-portfolio-intelligence-terminal.guidedTour`,
  `...terminal.params`, `apps.custom-techtrade-desk.params`) are gone from `apps.json` and from
  `workspace_contract_debt.json` (8 -> 5; only #1271 entries remain).
- **App `params` -> groups.** Shared context is now schema-native `groups` with
  `defaultValue`s. Every placement of a member lists the group; layout `state.params` presets
  are kept and equal the group default.

  | App | Group 1 (`ticker`, AAPL) | Group 2 (`param` `account_id`, demo) |
  |---|---|---|
  | Overview | `pi_whatif_diff` | `pi_xray_sector` |
  | Terminal | 19 symbol widgets (context bar, profile, key stats, price history, financials, statements, peers, earnings, revenue x2, price targets, dividends, technicals, competitors, complementary, analyst forecasts, what-if card/diff, paper ticket) | 17 account widgets (event calendar, book context, X-Ray x2, concentration, look-through, risk dashboard/vol, paper ticket/KPIs/backtest/performance/blotter, alerts, sentiment, smart money, news) |
  | TechTrade | `tt_scan_table` (discovery, no symbol param, per `review-app.md:82`) + signal, plan, order legs, simulate, validation, tuning, audit | none: no TechTrade widget takes an account |

- **Why `ticker` params.** The pinned Workspace source (`terminalpro/src/lib/utils/app.ts`,
  `getTickerParamName` / `updateWidgetGroupValues`) writes a ticker group's value only into a
  `type: "ticker"` param, so the 35 `symbol` params in `widgets.json` (all widgets, placed or
  not) are now `ticker`. A `param` group syncs only values among a param's inline `options`
  (`isValidParamOption`), so every `account_id` param (17) has the option
  `{"label": "Demo account (synthetic)", "value": "demo"}` and a description saying only the
  demo account is wired. No tier serves another account today (`tier_calls.py` has no account
  handling), so nothing usable was removed. No new route was needed (see decisions).
- **`guidedTour` -> prompts + description.** The ten-step routine is ten user questions of the
  form `Weekly review, step <n> of 10 (<tab name> > <widget name>): <question>` plus a plain
  summary in the Terminal description. Order, tab and focus widget are kept; internal codes
  (W0-W9, NB01-NB08, wiring notes) were dropped after review (see Review round).
- **Prompts and descriptions.** Overview 3 prompts, Terminal 12 (10 routine + 2), TechTrade 4.
  Descriptions rewritten for users (Terminal said "Eleven-tab" for 12 tabs; TechTrade said
  T2-T6 "land in follow-up cycles"). All defaults are portable: AAPL, SPY, `demo` account and
  basket.
- **Layouts.** TechTrade tabs widened to the 40-column grid (single-widget tabs 30 -> 40,
  Morning Scan and Workbench re-laid). Terminal and Overview geometry unchanged (already
  overlap-free).
- **`contracts.py`** (red first): `layout.overlap` (per tab, edges may touch),
  `layout.state.param.value` (a preset must be an inline option), `group.default.value`
  (a `param` group default must be an option of every member) and `group.type.mismatch` for a
  ticker-group member whose `symbol` param is not `ticker`.

## Decisions for the lead

1. Account group is a static `param` group with one demo option, not an `endpointParam` with a
   new `/pi/accounts/options` route. A route would add an MCP-cloned tool and capability-policy
   entries for a list that can only return `demo` until an account resolver exists. Switch to
   `endpointParam` when the resolver lands.
2. Symbol params became `ticker` in all 35 widgets (needed for the ticker group to sync).
   Standalone, Workspace shows its ticker picker instead of a text box.
3. Not grouped (no inline options, so a `param` group cannot sync them): `delta_shares` on the
   Risk tab what-if pair, `horizon_days` (7/14/30 differ on purpose), `segment`, `window` and
   `benchmark_symbol` (one widget each).
